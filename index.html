03

กิจกรรม/ผลงานเด่น

โปรเจกต์ที่ภาคภูมิใจและแสดงถึงความสามารถจริง

เข้าเยี่ยมชมศึกษาดูงาน ณ บริษัท อินเทอร์เน็ตประเทศไทย จำกัด(มหาชน) จังหวัดสระบุรี

ศึกษาโครงสร้างพื้นฐาน IT ระดับประเทศ ครอบคลุม Data Center, Network Infrastructure และแนวทางการบริหารจัดการความปลอดภัยทางไซเบอร์ในองค์กรขนาดใหญ่

เข้าเยี่ยมชม Zahira Farm (ซาฮิร่าฟาร์ม) การนำระบบ IoT มาประยุกต์ใช้ในการบริหารจัดการอย่างมีประสิทธิภาพ

เรียนรู้การนำ IoT Sensor มาใช้ใน Smart Farm ตรวจวัดสภาพแวดล้อม ความชื้น อุณหภูมิ และเชื่อมต่อกับ Cloud Platform เพื่อวิเคราะห์ข้อมูลแบบ Real-time

เข้าร่วมโครงการเปิดโลกทักษะ AI และความปลอดภัยทางไซเบอร์

อบรมหลักสูตร Microsoft AI Skills ครอบคลุม Machine Learning, Prompt Engineering และ Cybersecurity พื้นฐาน ได้รับความรู้ด้านการป้องกันภัยคุกคามและแนวทาง Zero Trust Security

วิทยากรฐานการเขียนโปรแกรมเบื้องต้น โครงการค่าย Turn IT On ครั้งที่ 17

ออกแบบและสอนเนื้อหาการเขียนโปรแกรมเบื้องต้นแก่นักเรียนมัธยมศึกษา ฝึกทักษะการสื่อสาร การถ่ายทอดความรู้ และการแก้ปัญหาเฉพาะหน้าในฐานะผู้สอน

Project IoT — ระบบตรวจจับสภาพอากาศในห้องครัว

พัฒนาระบบ IoT ด้วย ESP32 และ Sensor ตรวจจับแก๊ส/อุณหภูมิ ตรวจวัดควัน แก๊สรั่ว และความร้อนแบบ Real-time พร้อมระบบแจ้งเตือนอัตโนมัติ (LED, Buzzer, พัดลม) และ Live Dashboard ผ่าน Firebase และ NETPIE

Project AI — ตรวจจับโรคในใบมะเขือเทศด้วย Machine Learning

วิเคราะห์อาการโรคและสร้าง Dataset กว่า 1,000 ภาพด้วย Roboflow ฝึก Model YOLOv11 Object Detection ด้วย Python ได้ความแม่นยำสูงถึง 96% พร้อมประเมิน Feasibility สำหรับการใช้งานจริงในภาคเกษตร
